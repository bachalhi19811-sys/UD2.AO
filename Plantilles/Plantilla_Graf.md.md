


# Grafo de una red informática

## Introducción
Este grafo representa una pequeña red informática.

## Grafo

```mermaid
graph TD
    A[Router] --> B[Switch]
    B --> C[Ordenador 1]
    B --> D[Ordenador 2]
    B --> E[Impresora]
    B --> F[Servidor]
```

## Conclusión
El router conecta con el switch, que distribuye la conexión entre los diferentes dispositivos.
